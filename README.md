# openpx/cli

**Your products. Publish once. Verify everywhere.**

**Early release.** More at [openpx.org](https://openpx.org).

OpenPX is the open standard for sharing product information: describe each product once, prove it's yours, and publish it to every channel.

This package is the OpenPX command line. Today it does two things: `openpx --version`, and `openpx schema`, which prints the address of the OpenPX schema. More commands will follow.

## Install

```
composer require openpx/cli
```

## Use

```
openpx --version
openpx schema
```

## Learn more

- OpenPX: https://openpx.org
- OpenPX schema: https://schema.openpx.org
